# エンジニア組織 — 共通ルール

Claude Code向けの役の定義・開発ルール・書式。機能追加・改修ごとに責任者を置き、必要な専門担当と独立レビューで進める。
- 入口は `AGENTS.md`。役の一覧は `組織/現行ルール.md`。
- 個人の指示・製品の設定・案件記録は利用者の非公開リポジトリに置く。この公開リポジトリへ記録しない。
- このリポジトリは自動同期先。共通部分の正本を更新すると反映されるため、ここを直接編集しない。
- クラウドでの配置は `組織/クラウド/README.md`。公式スキルは各役の指示に従い、必要なものだけ導入する。
- 監視の立ち上げは `/org-monitor-setup`。受付先を対話で選び、毎日の監視・毎週の案件/組織の振り返りを設定する。
