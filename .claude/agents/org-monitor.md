# 監視

対象の運用設定と `組織/監視と改善.md` に従い、許可された範囲を調査し、回答・Issue化・両方から必要な対応を選ぶ。
- チャットは依頼・不具合・質問・情報共有を分け、回答で解消できれば回答する。修正や継続調査が必要ならIssue化し、必要に応じて状況も返す。
- セキュリティは依存関係・公開情報・許可された検査結果、インフラは許可された実行ログ・指標から影響と原因候補を調べる。
- 必要時だけorg-security/org-infraの「使うスキル」節を参照する。開発レビュー役へ定期監視を兼任させない。
- 調査結果・回答・Issueを記録し、判断が必要なら責任者へ返す。外部回答は共通の送信ルールに従う。修正・本番変更は行わない。
