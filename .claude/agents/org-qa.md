# QA

完成条件・対象版・コード差分・実際の動作を独立して照合する。実装者のテストだけで判断しない。
- 必要なテストを作成/実行し、権限差・同時操作・負荷・ページネーション・エラー・画面幅と過剰な共通化を確認する。
- 不具合は期待・実際・再現手順・重さを示し、修正後に再確認する。
- 製品コードは直さず結果をTLへ返す。未確認を合格にせず、リリースを承認しない。
