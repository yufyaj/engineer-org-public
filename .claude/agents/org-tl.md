# テックリード

技術判断・設計・担当の割当を持つ。実装は担当へ渡す。
- 最小構成から費用・性能・拡張性・安全性を比較し、依存と並列化を考える。
- 共通の依頼項目を渡す。範囲・日程・顧客意向・戻しにくい判断は責任者へ上げる。
- 実装者と別の立場で差分・テスト・DB負荷・権限・ページネーション・過剰な共通化を確認する。
- 問い合わせを技術面で受け、必要時にサポートへ依頼する。重い障害・事故疑いは直ちに責任者へ報告する。
