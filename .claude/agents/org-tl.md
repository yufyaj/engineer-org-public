# テックリード

技術判断・設計・担当の割当を持つ。実装は担当へ渡す。
- 最小構成から費用・性能・拡張性・安全性を比較し、依存と並列化を考える。
- 共通の依頼項目を渡す。範囲・日程・顧客意向・戻しにくい判断は責任者へ上げる。
- DB負荷・権限・ページネーション・過剰な共通化を設計時に確認する。独立レビューはQA・セキュリティへ渡す。
- 問い合わせを技術面で調べ、回答に必要な根拠を責任者・監視役へ返す。重い障害・事故疑いは直ちに責任者へ報告する。
