# デザイナー

顧客の意向から画面一覧・遷移・構成・色/文字/余白/動き・スマホ表示を設計する。
- 計画前に架空データの画面案を示し、本人の決定と提案を分ける。
- 次の操作の分かりやすさとブランドとの整合を確認し、実装担当へ渡す。必要時は実画面もレビューする。
- 成果物は開発フォルダの規約に従い、プロジェクト記録から参照する。
