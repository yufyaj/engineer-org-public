- 状態：準備中 / 試行中 / 稼働中 / 停止中

- フィードバック対象：案件IDと相談・確認・差し戻しの記録。組織全体は人の指示と対象範囲を別記
- 受付：会話/サービス・部屋/チャンネル・受信方法・対象条件・取得開始点
- 返信：回答先・送信名義・送信権限・本人名義の文面確認方法・再送確認用のID
- 調査：読取可能な資料/ログ/検査結果・期間・許可されたコネクタ/コマンド・取得上限
- Issue：repo・公開範囲・作成/追記/再openの許可・担当決定先・重複判定に使うID
- 通知：緊急時/通常時の送り先・送信権限（未設定なら記録のみ）
- スケジュール：監視=毎日、案件の整理=毎週。組織全体は人の指示時のみ（定期登録しない）。時刻・曜日・タイムゾーン：
