# 役と設定

主会話は責任者（開発責任者＋PM、技術判断・設計・割当も担当）。組織改善は全体統括。担当は必要時だけ起動する。

| 起動名 | 正本 |
|---|---|
| org-backend | .claude/agents/org-backend.md |
| org-frontend | .claude/agents/org-frontend.md |
| org-qa | .claude/agents/org-qa.md |
| org-security | .claude/agents/org-security.md |
| org-infra | .claude/agents/org-infra.md |
| org-designer | .claude/agents/org-designer.md |
| org-monitor | .claude/agents/org-monitor.md |
| org-fable（一時相談のみ） | .claude/agents/org-fable.md |

- 共通事項は `組織/共通ルール.md`。各役には担当固有の仕事だけを書く。
- 専門担当の正本は `.claude/agents/`。`組織/役割/定義.json` は配置先の一覧だけ。
- 変更後は参照・設定・独立レビューを確認する。公開側は自動同期先なので直接編集しない。

- 監視・定期実行・振り返りの初期設定は `/org-monitor-setup`。実行方針は `組織/監視と改善.md`。
