# 製品と案件

非公開の組織リポジトリで、製品ごとに次の構成を使う。この公開リポジトリには記録しない。

- `製品/<製品ID>/README.md`：製品情報・管理するrepo・本人が選んだ管理先。
- `製品/<製品ID>/案件/<案件ID>/README.md`：機能追加・改修の記録。必要時だけ要件・設計・計画を足す。
- `製品/<製品ID>/運用/`：監視・定期実行の設定と記録。実行場所によって分けない。
- `製品/<製品ID>/履歴/`：移行した過去の記録。

案件の書式は `組織/書式/プロジェクト記録.md`。コードと記録のrepo・branch・commit/PRを対応づける。
